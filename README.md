# Mira Collection - صفحة الهبوط

صفحة هبوط احترافية وحديثة لمتجر **Mira Collection** المتخصص في بيع ملابس أطفال بالجملة من تركيا.

## الميزات الرئيسية

### 1. **قسم البطل (Hero Section)**
- عنوان جذاب يعكس هوية العلامة التجارية
- وصف واضح للخدمة المقدمة
- أزرار استدعاء للعمل (CTA) بارزة
- إحصائيات توضح قوة العلامة التجارية (21K+ متابع، 100% جودة مضمونة، دعم 24/7)

### 2. **قسم قصة العلامة التجارية (About Section)**
- معلومات شاملة عن الشركة
- قائمة بالميزات الرئيسية
- بطاقات معلومات التواصل (الموقع، الهاتف، البريد الإلكتروني)

### 3. **قسم الخدمات (Services Section)**
- 6 بطاقات خدمة توضح المميزات:
  - تنوع المنتجات
  - أسعار تنافسية
  - توصيل سريع
  - دعم عملاء متميز
  - ضمان الجودة
  - شراكات موثوقة

### 4. **معرض المنتجات (Gallery Section)**
- عرض شبكي لأنواع المنتجات المختلفة
- 6 فئات منتجات:
  - ملابس صيفية للأطفال
  - ملابس شتوية دافئة
  - ملابس رسمية وحفلات
  - ملابس رياضية نشيطة
  - ملابس نوم مريحة
  - إكسسوارات وملحقات

### 5. **قسم آراء العملاء (Testimonials Section)**
- 3 شهادات من عملاء راضين
- تقييمات 5 نجوم
- معلومات العميل (الاسم والدور)

### 6. **نموذج الاتصال (Contact Form)**
- حقول مدخلات شاملة:
  - الاسم الكامل
  - البريد الإلكتروني
  - رقم الهاتف
  - الموضوع (استفسار عام، طلب جملة، شراكة تجارية، أخرى)
  - الرسالة
- تكامل مع WhatsApp للتواصل المباشر
- التحقق من صحة البيانات
- رسائل نجاح وخطأ تفاعلية

### 7. **التنقل والرأس (Navigation Header)**
- شريط تنقل ثابت (sticky)
- روابط سريعة لجميع الأقسام
- زر WhatsApp سريع الوصول
- شعار العلامة التجارية

### 8. **التذييل (Footer)**
- معلومات الشركة
- روابط سريعة
- معلومات التواصل
- حقوق النشر

- تحسين الأداء
